# cyber_portfolio — hackergovind

Cybersecurity researcher + frontend developer portfolio built with Next.js 15, React 19, TypeScript, and Tailwind CSS v4.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
```

Production:

```bash
npm run build
npm start        # http://localhost:3000
```

Verified: `npm run build` passes and `npx next start` serves the homepage with HTTP 200.
